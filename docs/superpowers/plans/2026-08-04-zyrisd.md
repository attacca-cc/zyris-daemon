# zyrisd implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an always-on daemon that installs on the user's machine, comes up at boot, and
attaches to Attacca as a Zyris node to serve its terminal, files, and (with a display) screen and input.

**Architecture:** `zyris`'s `Runner` already handles dialing, backoff, and reconnect, so what zyrisd
adds is four layers — (1) `Credentials` that never starts enrollment, (2) a gate implementing the
`FileIo`/`Terminal` traits to fence paths and resources, (3) a lifecycle for SIGTERM, exit codes, and
the idle watch, (4) install and the desktop child process. Splitting into two workspaces makes it
structurally impossible for graphics libraries to link into the parent binary.

**Tech Stack:** Rust 2021 · tokio · zyris (pinned git rev) · toml + serde · systemd user unit ·
cargo-deb · POSIX sh

**Design spec:** `docs/superpowers/specs/2026-08-04-zyris-daemon-design.md` — every "why" behind this
plan lives there. On conflict, the spec wins.

## Global Constraints

- **The pinned zyris rev is `75f7e5d0f98baa1f72c63c762fb8e577d4b0638e`.** Both workspaces declare it
  exactly once in their own `[workspace.dependencies]` with an explicit `rev = "…"`. Member crates
  use only `workspace = true`.
- **Always run `cargo` at `-j2` or lower.** This machine has 3.6GB RAM / 4 threads, and the default
  `-j4` eats all the memory at link time.
- **Never use `cargo build --workspace` / `cargo test --workspace`.** Feature unification spans
  the whole workspace, so narrow it with `-p <crate>`. Build `display/` separately with
  `--manifest-path`.
- **Never run `cargo fmt`.** Don't introduce a `rustfmt.toml`; match the surrounding line width
  (96-104 columns) by eye.
- Comments and doc comments say **why**, in plain declarative prose. Test function names are
  English snake_case, with a doc comment above stating what the test protects.
- Tests live in an inline `mod tests` at the bottom of the source file.
- **Commits stay local.** This repo has no remote; never push.
- The credentials path is **literally** `$HOME/.config/zyrisd/credentials.json`. It does not look at
  `XDG_CONFIG_HOME`.
- The config path is literally `$HOME/.config/zyrisd/config.toml`.

- [ ] **Step 5: Write `scripts/check-zyris-pin.sh`**

```bash
#!/usr/bin/env bash
# Check that the zyris git dependency is pinned to the same rev in both workspaces.
#
# Declared without a rev, Cargo.lock is the only pin, and one `cargo update` silently slides to the
# tip of the default branch. A product that ships binaries must not build differently day to day.
set -euo pipefail
cd "$(dirname "$0")/.."

REV="75f7e5d0f98baa1f72c63c762fb8e577d4b0638e"
fail=0

check_manifest() {
  local manifest="$1"; shift
  for c in "$@"; do
    local line
    line=$(grep -E "^${c} = " "$manifest" || true)
    if [[ -z "$line" ]]; then
      echo "✗ ${manifest} has no ${c} declaration"; fail=1; continue
    fi
    if [[ "$line" != *"rev = \"${REV}\""* ]]; then
      echo "✗ ${c} in ${manifest} is not pinned to ${REV}"; fail=1
    fi
  done
}

check_manifest Cargo.toml zyris zyris-caps zyris-capkit
check_manifest display/Cargo.toml zyris zyris-caps zyris-capkit

# A member crate that declares the git dependency directly bypasses the workspace pin.
for m in crates/*/Cargo.toml; do
  if grep -qE '^zyris[a-z-]* = \{ git' "$m"; then
    echo "✗ ${m} declares zyris directly. Use workspace = true"; fail=1
  fi
done

for lock in Cargo.lock display/Cargo.lock; do
  [[ -f "$lock" ]] || continue
  if ! grep -q "rev=${REV}#${REV}" "$lock"; then
    echo "✗ ${lock} does not point at ${REV}"; fail=1
  fi
done

if [[ $fail -eq 0 ]]; then
  echo "✓ zyris is pinned to ${REV} in both workspaces"
fi
exit $fail
```

# CLAUDE.md

zyrisd — an always-on daemon that installs on the user's machine, comes up at boot, and attaches to
Attacca as a Zyris node to serve its terminal, files, and (with a display) screen and input.

Every "why" behind the design is in `docs/superpowers/specs/2026-08-04-zyris-daemon-design.md`.
This file doesn't summarize it. It lists only **the things that bite if you don't know them first**.

## Why there are two workspaces

This repo has two Cargo workspaces, and that is the most important structural fact about it.

| What | Where | Links graphics |
|---|---|---|
| `zyrisd` (bin), `zyrisd-node`, `zyrisd-display-proto` | root workspace | ✗ |
| `zyrisd-display` (bin) | `display/` — **its own workspace root** | ✓ |

**The unit of Cargo feature unification is not the crate but every workspace member pulled into a
single cargo invocation.** With both in one workspace, one `cargo build --workspace` unifies
`zyris-capkit`'s `desktop` feature and nails X11/Wayland/mesa/pipewire into the parent as `DT_NEEDED`.
Then on a headless machine without those `.so`s it dies before it ever reaches `main`.

So there are always two builds:

```bash
cargo build -p zyrisd -j2                                 # parent
cargo build --manifest-path display/Cargo.toml -j2        # child
```

`cargo build --workspace` and `cargo test --workspace` are **never used.**
Verify the parent links no graphics with `readelf -d target/release/zyrisd | grep NEEDED`.

## Constraints of this machine

3.6GB RAM / 4 threads. **Always run `cargo` at `-j2` or lower.** The desktop child builds zbus,
pipewire bindgen, and wayland-scanner, so it is especially heavy.

## Traps

- **Don't run `cargo fmt`.** There is no `rustfmt.toml` and the code is written at 96-104 columns.
- **Build the `PtyTerminal` instance once and never build another.** The session cap is per instance
  and the reaper sweeper holds a `Weak`, so dropping it takes every open PTY session with it. That is
  why attaching and detaching the desktop capability uses only `Capabilities::add`/`remove` and never
  hands a new instance to `replace()`.
- **Don't delegate to upstream `exec`.** `PtyTerminal::exec` spawns the child inside itself and
  returns only the string it drained with `cmd.output()`, leaving no way to kill the process group
  from outside. `GatedTerminal::exec` is implemented directly.
- **`Credentials::refresh()` must call `Enroller::force_refresh`.** Dropping only the in-memory copy
  leaves the dead token in the store; presented again, the runner folds the second 401 to `Refused`.
- **Don't fold `force_refresh`'s `Transport` error into `NeedsOperator`.** One 503 during a server
  deploy becomes exit code 2, and `RestartPreventExitStatus=2` permanently stops every daemon that
  happened to be reconnecting at that moment.
- **Logs go to stderr.** `zyrisd enroll` prints its enrollment code block on stdout; mixing the two
  wrecks the one screen a human actually has to read.
- When bumping upstream `zyris`, `./scripts/check-zyris-pin.sh` must pass.

`crates/zyrisd-node/src/config.rs`:

```rust
//! `$HOME/.config/zyrisd/config.toml`.
//!
//! Taking the path from a literal `$HOME` is the whole point. The idiomatic `XDG_CONFIG_HOME` version
//! breaks because the systemd user manager environment has no such variable, so `zyrisd enroll`
//! (login shell) and `zyrisd run` (unit) can end up reading different files.

use std::path::{Path, PathBuf};

use serde::Deserialize;

#[derive(Debug, thiserror::Error)]
pub enum ConfigError {
    #[error("config file syntax error: {0}")]
    Syntax(String),
    #[error("invalid configuration: {0}")]
    Invalid(String),
    #[error("$HOME is not set")]
    NoHome,
}

#[derive(Debug, Clone, PartialEq, Eq, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct Config {
    pub node: NodeConfig,
    pub files: FilesConfig,
    pub terminal: TerminalConfig,
    pub desktop: DesktopConfig,
    pub notify: NotifyConfig,
}

#[derive(Debug, Clone, PartialEq, Eq, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct NodeConfig {
    /// Defaults to `<hostname>-<username>`. Hostname alone means two users on one machine show up
    /// as two identically named nodes in Attacca, and nothing in the install flow catches it.
    pub name: String,
    pub server_url: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct FilesConfig {
    /// `roots[0]` is the base for relative paths and the PTY cwd, because upstream takes exactly one
    /// root. The rest serve only as an absolute-path allowlist.
    pub roots: Vec<PathBuf>,
    pub deny: Vec<PathBuf>,
}

#[derive(Debug, Clone, PartialEq, Eq, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct TerminalConfig {
    /// stdout+stderr combined. Not 1 MiB, because Attacca measures tool results with
    /// `serde_json::to_vec().len()` and compares against `ZYRIS_MAX_RESULT_BYTES` (default 1,000,000)
    /// — 1 MiB already blows that budget before JSON escaping.
    pub max_output_bytes: usize,
    /// The effective timeout is `min(what the caller passed, this)`.
    pub exec_timeout_secs: u64,
    /// Variables cleared before handing off to PTY and exec. The two defaults carry **credentials
    /// that reach other machines**, so the blast radius leaves this one. Undo with `unset_env = []`.
    pub unset_env: Vec<String>,
}

#[derive(Debug, Clone, PartialEq, Eq, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct DesktopConfig {
    pub enabled: bool,
}

#[derive(Debug, Clone, PartialEq, Eq, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct NotifyConfig {
    pub enabled: bool,
}

impl Default for Config {
    fn default() -> Config {
        Config {
            node: NodeConfig::default(),
            files: FilesConfig::default(),
            terminal: TerminalConfig::default(),
            desktop: DesktopConfig { enabled: true },
            notify: NotifyConfig { enabled: true },
        }
    }
}

impl Default for NodeConfig {
    fn default() -> NodeConfig {
        NodeConfig { name: default_node_name(), server_url: zyris::DEFAULT_SERVER_URL.to_string() }
    }
}

impl Default for FilesConfig {
    fn default() -> FilesConfig {
        FilesConfig { roots: vec![PathBuf::from("~")], deny: Vec::new() }
    }
}

impl Default for TerminalConfig {
    fn default() -> TerminalConfig {
        TerminalConfig {
            max_output_bytes: 256 * 1024,
            exec_timeout_secs: 120,
            unset_env: vec!["SSH_AUTH_SOCK".to_string(), "GPG_AGENT_INFO".to_string()],
        }
    }
}

impl Default for DesktopConfig {
    fn default() -> DesktopConfig {
        DesktopConfig { enabled: true }
    }
}

impl Default for NotifyConfig {
    fn default() -> NotifyConfig {
        NotifyConfig { enabled: true }
    }
}

fn default_node_name() -> String {
    let host = zyris::machine_name().unwrap_or_else(|| "zyrisd".to_string());
    match std::env::var("USER").ok().filter(|u| !u.is_empty()) {
        Some(user) => format!("{host}-{user}"),
        None => host,
    }
}

pub fn home() -> Result<PathBuf, ConfigError> {
    std::env::var_os("HOME")
        .filter(|h| !h.is_empty())
        .map(PathBuf::from)
        .ok_or(ConfigError::NoHome)
}

/// `$HOME/.config/zyrisd`. Does not look at `XDG_CONFIG_HOME` — see the module comment above.
pub fn config_dir() -> PathBuf {
    home().unwrap_or_else(|_| PathBuf::from("/nonexistent")).join(".config").join("zyrisd")
}

pub fn config_path() -> PathBuf {
    config_dir().join("config.toml")
}

pub fn credentials_path() -> PathBuf {
    config_dir().join("credentials.json")
}

/// Expands only `~` and `~/`. `~user` is not supported.
fn expand_tilde(raw: &str, home: &Path) -> PathBuf {
    if raw == "~" {
        return home.to_path_buf();
    }
    match raw.strip_prefix("~/") {
        Some(rest) => home.join(rest),
        None => PathBuf::from(raw),
    }
}

fn parse(text: &str, home: &Path) -> Result<Config, ConfigError> {
    let mut cfg: Config =
        toml::from_str(text).map_err(|e| ConfigError::Syntax(e.to_string()))?;
    cfg.files.roots = expand_all(&cfg.files.roots, home)?;
    cfg.files.deny = expand_all(&cfg.files.deny, home)?;
    if cfg.files.roots.is_empty() {
        return Err(ConfigError::Invalid("files.roots is empty".into()));
    }
    if cfg.terminal.max_output_bytes == 0 {
        return Err(ConfigError::Invalid("terminal.max_output_bytes cannot be 0".into()));
    }
    Ok(cfg)
}

fn expand_all(raw: &[PathBuf], home: &Path) -> Result<Vec<PathBuf>, ConfigError> {
    raw.iter()
        .map(|p| {
            let expanded = expand_tilde(&p.to_string_lossy(), home);
            if expanded.is_absolute() {
                Ok(expanded)
            } else {
                Err(ConfigError::Invalid(format!(
                    "path must be absolute (or start with ~): {}",
                    p.display()
                )))
            }
        })
        .collect()
}

/// Defaults when the file is absent. Otherwise read and validate it.
pub fn load() -> Result<Config, ConfigError> {
    let home = home()?;
    let path = config_path();
    match std::fs::read_to_string(&path) {
        Ok(text) => parse(&text, &home),
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
            let mut cfg = Config::default();
            cfg.files.roots = expand_all(&cfg.files.roots, &home)?;
            Ok(cfg)
        }
        Err(e) => Err(ConfigError::Invalid(format!("cannot read {}: {e}", path.display()))),
    }
}

impl Config {
    /// Produces the roots and denies that will actually be used.
    ///
    /// A missing root is warned about and dropped. One late mount (NFS, automount, removable, LUKS)
    /// kills the daemon that came up right after boot, systemd gives up restarting it by design, and
    /// a human must start it by hand when the mount arrives 10s later. Dropping a root only narrows.
    pub fn resolve_roots(&self) -> (Vec<PathBuf>, Vec<PathBuf>) {
        let roots: Vec<PathBuf> = self
            .files
            .roots
            .iter()
            .filter(|r| {
                let ok = r.exists();
                if !ok {
                    tracing::warn!(root = %r.display(), "root missing, dropping from the allowlist");
                }
                ok
            })
            .cloned()
            .collect();
        let mut deny = self.files.deny.clone();
        deny.push(config_dir());
        (roots, deny)
    }
}
```

```rust
//! A credential source that never starts enrollment.
//!
//! Upstream `DeviceGrant` on the daemon path **prints an enroll code to stdout (= the journal)**
//! every boot, blocks up to 30 min, then dies. The code goes out via `println!`, not `tracing`, so
//! `RUST_LOG` cannot silence it. So the daemon uses only what is stored, else it calls a human.

use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;

use zyris::enroll::{CredentialStore, CredentialStoreError, EnrollError, Enroller, StoredCredential};
use zyris::runtime::{Credentials, CredentialsError};

/// Same as upstream `DeviceGrant`. A bit of clock skew still won't present a near-expired token.
const SKEW_SECS: i64 = 30;

pub struct StoredOnly {
    store: Arc<dyn CredentialStore>,
    /// We never enroll, but the **only public API that reaches the refresh endpoint** is
    /// `Enroller::force_refresh`, so we need an instance.
    enroller: Enroller,
    held: tokio::sync::Mutex<Option<StoredCredential>>,
    /// Tells `main` "this credential is definitely dead".
    ///
    /// `RunError::Refused` folds in every `WireError` with `retriable == false`, so a 500
    /// during a deploy lands there too. Rather than sniffing strings, the place that actually saw
    /// the revocation marks it. That is what splits exit 2 (give up) from exit 1 (restart).
    gave_up: AtomicBool,
}

pub fn file_store() -> Arc<dyn CredentialStore> {
    Arc::new(zyris::enroll::FileCredentialStore::at(crate::config::credentials_path()))
}

impl StoredOnly {
    pub fn new(
        server_url: &str,
        node_name: String,
        store: Arc<dyn CredentialStore>,
    ) -> Result<StoredOnly, EnrollError> {
        // Scopes stay empty. zyrisd only serves tools and has no reason to touch the owner account,
        // and `Runner::request_scopes` never reaches Enroller when we pass our own Credentials.
        let enroller = Enroller::new(
            server_url,
            node_name,
            platform().to_string(),
            Vec::new(),
            store.clone(),
        )?;
        Ok(StoredOnly {
            store,
            enroller,
            held: tokio::sync::Mutex::new(None),
            gave_up: AtomicBool::new(false),
        })
    }

    pub fn gave_up(&self) -> bool {
        self.gave_up.load(Ordering::SeqCst)
    }

    /// Rotates an expired credential. The three outcomes mean different things.
    async fn rotate(&self, current: &StoredCredential) -> Result<StoredCredential, CredentialsError> {
        match self.enroller.force_refresh(current).await {
            Ok(Some(rotated)) => Ok(rotated),
            // The server refused. `force_refresh` has already cleared the store.
            Ok(None) => {
                self.gave_up.store(true, Ordering::SeqCst);
                Err(CredentialsError::NeedsOperator(
                    "Credential revoked. Run zyrisd enroll again".into(),
                ))
            }
            // Could not reach the server. The credential may be fine, so never delete it.
            Err(EnrollError::Transport(e)) => Err(CredentialsError::Unavailable(e)),
            Err(e) => Err(CredentialsError::NeedsOperator(e.to_string())),
        }
    }
}

fn platform() -> &'static str {
    match std::env::consts::OS {
        "linux" => "linux",
        "macos" => "macos",
        "windows" => "windows",
        _ => "other",
    }
}

fn now_unix() -> i64 {
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map(|d| d.as_secs() as i64)
        .unwrap_or(0)
}

/// Splits store errors three ways.
///
/// The upstream file backend marks **every `io::Error` discardable**, so transient read failures
/// like EACCES/EIO/ESTALE sit in the same bucket as a corrupt file. Folding them all into
/// `NeedsOperator` turns a transient condition into a permanent outage.
fn store_error(e: CredentialStoreError) -> CredentialsError {
    let text = e.to_string();
    if !e.is_discardable() {
        // Permissions are too open, or the config directory is missing. A human must fix it.
        return CredentialsError::NeedsOperator(text);
    }
    if text.contains("version") || text.contains("corrupt") || text.contains("parse") {
        return CredentialsError::NeedsOperator(format!(
            "{text} — run zyrisd enroll again"
        ));
    }
    CredentialsError::Unavailable(text)
}

#[zyris::async_trait]
impl Credentials for StoredOnly {
    async fn bearer(&self) -> Result<String, CredentialsError> {
        let mut held = self.held.lock().await;
        if let Some(token) = held.as_ref().and_then(|c| c.bearer(now_unix(), SKEW_SECS)) {
            return Ok(token.to_string());
        }
        let stored = self.store.load().await.map_err(store_error)?;
        let Some(stored) = stored else {
            return Err(CredentialsError::NeedsOperator(
                "Not enrolled. Run zyrisd enroll".into(),
            ));
        };
        let fresh = match stored.bearer(now_unix(), SKEW_SECS) {
            Some(_) => stored,
            None => self.rotate(&stored).await?,
        };
        let token = fresh
            .bearer(now_unix(), SKEW_SECS)
            .ok_or_else(|| {
                CredentialsError::NeedsOperator(
                    "Freshly issued credential is already expired. Check this machine's clock".into(),
                )
            })?
            .to_string();
        *held = Some(fresh);
        Ok(token)
    }

    /// Called once by the runner after it gets a 401.
    ///
    /// **It must call `force_refresh`.** Dropping only the in-memory copy leaves the store intact,
    /// so the next `bearer()` hands out the same dead token; the runner already rotated once, so it
    /// folds the second 401 straight into `Refused` — store not cleared, no re-enroll hint given.
    async fn refresh(&self) -> Result<bool, CredentialsError> {
        let mut held = self.held.lock().await;
        let Some(current) = held.take() else { return Ok(false) };
        match self.rotate(&current).await {
            Ok(rotated) => {
                *held = Some(rotated);
                Ok(true)
            }
            Err(CredentialsError::NeedsOperator(_)) if self.gave_up() => Ok(false),
            Err(e) => Err(e),
        }
    }

    fn describe(&self) -> String {
        format!("stored credential ({})", self.enroller.store_description())
    }
}
```

```rust
//! The path gate.
//!
//! Upstream `resolve_under` allows absolute paths outside the root, and that contract is pinned by
//! docs, unit tests, and integration tests ("the root is a default, not a jail"). Without this
//! layer the config's `roots` is decoration.
//!
//! **This gate stops accidents, not intruders.** As long as we serve `terminal`, an agent can open
//! any file through the shell anyway. The one exception is the credential directory, because its
//! blast radius reaches past this machine (§5.2).

use std::path::{Component, Path, PathBuf};

use zyris::{ErrorCode, WireError};

pub struct PathGate {
    roots: Vec<PathBuf>,
    deny: Vec<PathBuf>,
}

impl PathGate {
    pub fn new(roots: Vec<PathBuf>, deny: Vec<PathBuf>) -> PathGate {
        PathGate { roots, deny }
    }

    /// Base for relative paths and PTY cwd. Upstream takes one root, so only this one goes down.
    pub fn root(&self) -> &Path {
        self.roots.first().map(PathBuf::as_path).unwrap_or_else(|| Path::new("/"))
    }

    pub fn check(&self, requested: &str) -> zyris::Result<PathBuf> {
        let joined = join_like_upstream(self.root(), requested);
        let resolved = canonicalize_deepest(&joined);

        if self.deny.iter().any(|d| is_under(&resolved, d)) {
            return Err(self.refuse(requested, "is on the deny list"));
        }
        if !self.roots.iter().any(|r| is_under(&resolved, r)) {
            return Err(self.refuse(requested, "is outside the allowed roots"));
        }
        Ok(resolved)
    }

    fn refuse(&self, requested: &str, why: &str) -> WireError {
        let roots: Vec<String> = self.roots.iter().map(|r| r.display().to_string()).collect();
        WireError::new(
            ErrorCode::ForbiddenScope,
            format!("{requested}: {why}. Paths this node allows: {}", roots.join(", ")),
        )
    }
}

/// Joins by the same rule as upstream `resolve_under` — if the path the gate checked and the path
/// the layer below opens differ, the check is meaningless.
fn join_like_upstream(root: &Path, path: &str) -> PathBuf {
    let requested = Path::new(path);
    let mut out = if requested.has_root() { PathBuf::new() } else { root.to_path_buf() };
    for component in requested.components() {
        match component {
            Component::Prefix(p) => out.push(p.as_os_str()),
            Component::RootDir => out.push(Component::RootDir.as_os_str()),
            Component::CurDir => {}
            Component::ParentDir => {
                if !out.pop() && !out.has_root() {
                    out.push("..");
                }
            }
            Component::Normal(part) => out.push(part),
        }
    }
    out
}

/// Really resolves down to the deepest existing ancestor, then joins the rest logically.
///
/// `write`/`mkdir` take paths that do not exist yet as normal targets, so a plain `canonicalize`
/// fails with `NotFound` and blocks every write. Resolving only the ancestor still stops symlink
/// escapes while letting new files through.
fn canonicalize_deepest(path: &Path) -> PathBuf {
    let mut existing = path.to_path_buf();
    let mut tail: Vec<std::ffi::OsString> = Vec::new();
    loop {
        match existing.canonicalize() {
            Ok(real) => {
                let mut out = real;
                for part in tail.iter().rev() {
                    out.push(part);
                }
                return out;
            }
            Err(_) => match existing.file_name() {
                Some(name) => {
                    tail.push(name.to_os_string());
                    if !existing.pop() {
                        return path.to_path_buf();
                    }
                }
                None => return path.to_path_buf(),
            },
        }
    }
}

fn is_under(path: &Path, base: &Path) -> bool {
    let base = base.canonicalize().unwrap_or_else(|_| base.to_path_buf());
    path == base || path.starts_with(&base)
}
```

```rust
//! Wraps `Terminal`. The PTY calls are delegated; only `exec` is rewritten.

use std::path::Path;
use std::process::Stdio;
use std::time::Duration;

use tokio::io::AsyncReadExt;
use zyris::{Blob, Streaming};
use zyris_capkit::PtyTerminal;
use zyris_caps::{
    ExecOutput, PtyChunk, PtyId, PtyOpened, PtyRead, PtyScreen, Settle, Terminal,
};

use crate::config::TerminalConfig;
use crate::gate::PathGate;

pub struct GatedTerminal {
    gate: PathGate,
    cfg: TerminalConfig,
    /// **Built once and never rebuilt.** The session cap is per instance and the sweeper holds a
    /// `Weak`, so dropping it takes every open PTY session with it.
    inner: PtyTerminal,
}

impl GatedTerminal {
    pub fn new(gate: PathGate, cfg: TerminalConfig) -> GatedTerminal {
        let inner = PtyTerminal::rooted(gate.root().to_path_buf());
        GatedTerminal { gate, cfg, inner }
    }

    fn effective_timeout(&self, caller_ms: Option<u64>) -> Duration {
        let cap_ms = self.cfg.exec_timeout_secs.saturating_mul(1000);
        Duration::from_millis(caller_ms.map(|c| c.min(cap_ms)).unwrap_or(cap_ms))
    }
}

/// Reads up to the cap only. Past it, stops reading and leaves a truncation marker.
async fn read_capped<R: tokio::io::AsyncRead + Unpin>(mut r: R, cap: usize) -> (Vec<u8>, bool) {
    let mut out = Vec::new();
    let mut buf = [0u8; 8192];
    loop {
        match r.read(&mut buf).await {
            Ok(0) | Err(_) => return (out, false),
            Ok(n) => {
                let room = cap.saturating_sub(out.len());
                out.extend_from_slice(&buf[..n.min(room)]);
                if out.len() >= cap {
                    return (out, true);
                }
            }
        }
    }
}

#[cfg(unix)]
fn kill_group(pid: i32, sig: i32) {
    // A negative pid means the whole process group. We spawned with `process_group(0)`, so the
    // child's pid is the group id, and grandchildren under it die with it.
    unsafe { libc::kill(-pid, sig) };
}

#[zyris::async_trait]
impl Terminal for GatedTerminal {
    async fn open(&self, shell: Option<String>, cols: u16, rows: u16) -> zyris::Result<PtyOpened> {
        self.inner.open(shell, cols, rows).await
    }

    async fn open_stream(
        &self,
        shell: Option<String>,
        cols: u16,
        rows: u16,
    ) -> zyris::Result<Streaming<PtyOpened, PtyChunk>> {
        self.inner.open_stream(shell, cols, rows).await
    }

    async fn read(
        &self,
        pty: PtyId,
        input: Option<String>,
        settle: Option<Settle>,
    ) -> zyris::Result<PtyRead> {
        self.inner.read(pty, input, settle).await
    }

    async fn screen(
        &self,
        pty: PtyId,
        input: Option<String>,
        settle: Option<Settle>,
    ) -> zyris::Result<PtyScreen> {
        self.inner.screen(pty, input, settle).await
    }

    async fn write(&self, pty: PtyId, data: Blob) -> zyris::Result<()> {
        self.inner.write(pty, data).await
    }

    async fn resize(&self, pty: PtyId, cols: u16, rows: u16) -> zyris::Result<()> {
        self.inner.resize(pty, cols, rows).await
    }

    async fn close(&self, pty: PtyId) -> zyris::Result<()> {
        self.inner.close(pty).await
    }

    async fn exec(
        &self,
        command: String,
        cwd: Option<String>,
        timeout_ms: Option<u64>,
    ) -> zyris::Result<ExecOutput> {
        let dir = match cwd {
            Some(c) => self.gate.check(&c)?,
            None => self.gate.root().to_path_buf(),
        };

        let mut cmd = tokio::process::Command::new("/bin/sh");
        cmd.arg("-c")
            .arg(&command)
            .current_dir(&dir)
            .stdin(Stdio::null())
            .stdout(Stdio::piped())
            .stderr(Stdio::piped());
        for key in &self.cfg.unset_env {
            cmd.env_remove(key);
        }
        #[cfg(unix)]
        cmd.process_group(0);

        let mut child = cmd.spawn().map_err(|e| {
            zyris::WireError::new(zyris::ErrorCode::Internal, format!("cannot run: {e}"))
        })?;
        let pid = child.id().unwrap_or(0) as i32;
        let cap = self.cfg.max_output_bytes;
        let mut stdout = child.stdout.take().expect("piped");
        let mut stderr = child.stderr.take().expect("piped");

        let collect = async {
            let (o, oc) = read_capped(&mut stdout, cap).await;
            let (e, ec) = read_capped(&mut stderr, cap).await;
            let status = child.wait().await;
            (o, oc, e, ec, status)
        };

        match tokio::time::timeout(self.effective_timeout(timeout_ms), collect).await {
            Ok((o, oc, e, ec, status)) => Ok(ExecOutput {
                exit_code: status.ok().and_then(|s| s.code()).unwrap_or(-1),
                stdout: finish(o, oc),
                stderr: finish(e, ec),
                timed_out: false,
            }),
            Err(_) => {
                #[cfg(unix)]
                {
                    kill_group(pid, libc::SIGTERM);
                    tokio::time::sleep(Duration::from_millis(200)).await;
                    kill_group(pid, libc::SIGKILL);
                }
                Ok(ExecOutput {
                    exit_code: -1,
                    stdout: String::new(),
                    stderr: "command timed out; the whole process group was killed".into(),
                    timed_out: true,
                })
            }
        }
    }
}

fn finish(bytes: Vec<u8>, capped: bool) -> String {
    let mut s = String::from_utf8_lossy(&bytes).to_string();
    if capped {
        s.push_str("\n… output was truncated at the cap");
    }
    s
}
```

```rust
//! Assembles the node, keeps it alive, and dies properly when it dies.

use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, Mutex};
use std::time::Duration;

use zyris::runtime::{RunError, Runner};
use zyris::{Connection, NodeKind};
use zyris_caps::{FileIoServer, TerminalServer};

use crate::config::Config;
use crate::credentials::{file_store, StoredOnly};
use crate::file_io::GatedFileIo;
use crate::gate::PathGate;
use crate::terminal::GatedTerminal;

/// Long enough for the close frame to reach the server. Same value as upstream `CLOSE_GRACE`.
const CLOSE_GRACE: Duration = Duration::from_millis(200);

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Exit {
    Ok,
    Retry,
    NeedsOperator,
}

impl Exit {
    pub fn code(&self) -> u8 {
        match self {
            Exit::Ok => 0,
            Exit::Retry => 1,
            Exit::NeedsOperator => 2,
        }
    }
}

/// Splits `Refused` two ways.
///
/// Only a definitely dead credential is 2 (= stop restarting). Everything else is 1 and restarts.
fn classify_refused(credential_gave_up: bool) -> Exit {
    if credential_gave_up {
        Exit::NeedsOperator
    } else {
        Exit::Retry
    }
}

/// Where the live connection is handed to the signal handler.
#[derive(Clone)]
pub struct ConnSlot(Arc<Mutex<Option<Connection>>>);

impl ConnSlot {
    pub fn new() -> ConnSlot {
        ConnSlot(Arc::new(Mutex::new(None)))
    }

    pub fn put(&self, conn: Connection) {
        *self.0.lock().unwrap() = Some(conn);
    }

    /// The slot is not cleared on a drop, so it may hold a dead connection.
    pub fn close(&self) {
        if let Some(conn) = self.0.lock().unwrap().as_ref() {
            if !conn.is_closed() {
                conn.close("zyrisd shutting down");
            }
        }
    }
}

impl Default for ConnSlot {
    fn default() -> ConnSlot {
        ConnSlot::new()
    }
}

pub async fn run(cfg: Config) -> Exit {
    let (roots, deny) = cfg.resolve_roots();
    if roots.is_empty() {
        tracing::error!("none of the configured roots exist; waiting for a mount");
        return Exit::Retry;
    }

    let store = file_store();
    let credentials = match StoredOnly::new(&cfg.node.server_url, cfg.node.name.clone(), store) {
        Ok(c) => Arc::new(c),
        Err(e) => {
            tracing::error!(error = %e, "cannot prepare credentials");
            return Exit::NeedsOperator;
        }
    };

    let mut run_config = zyris::runtime::RunConfig::from_env();
    run_config.url = cfg.node.server_url.clone();
    run_config.node_name = cfg.node.name.clone();
    run_config.kind = NodeKind::Service;

    // The instance holding `PtyTerminal` is built exactly once, here.
    let terminal = GatedTerminal::new(
        PathGate::new(roots.clone(), deny.clone()),
        cfg.terminal.clone(),
    );
    let files = GatedFileIo::new(PathGate::new(roots, deny));

    let slot = ConnSlot::new();
    let hook_slot = slot.clone();
    let runner = Runner::new(run_config, credentials.clone())
        .capability(TerminalServer(terminal))
        .capability(FileIoServer(files))
        // Filling the slot inside the returned future risks a signal arriving before it is scheduled.
        // Fill it synchronously in the closure **body** and return an empty future.
        .on_connect(move |conn| {
            hook_slot.put(conn);
            std::future::ready(())
        });

    let running = tokio::spawn(runner.try_run());

    tokio::select! {
        outcome = running => match outcome {
            Ok(Ok(())) => Exit::Ok,
            Ok(Err(e)) => {
                tracing::error!(error = %e, "zyrisd stopped");
                match e {
                    RunError::Credentials(zyris::runtime::CredentialsError::NeedsOperator(_)) => {
                        Exit::NeedsOperator
                    }
                    RunError::Build(_) => Exit::NeedsOperator,
                    RunError::Refused(_) => classify_refused(credentials.gave_up()),
                    _ => Exit::Retry,
                }
            }
            Err(e) => {
                tracing::error!(error = %e, "the node task panicked");
                Exit::Retry
            }
        },
        _ = terminate() => {
            tracing::info!("received a shutdown signal");
            slot.close();
            tokio::time::sleep(CLOSE_GRACE).await;
            Exit::Ok
        }
    }
}

/// Catches both SIGTERM and SIGINT.
///
/// Upstream `Runner` waits only on `ctrl_c()` (= SIGINT), and only while a connection is alive.
/// systemd stops us with SIGTERM, so as-is we die without a close frame, and a signal that arrives
/// while dialing or waiting in backoff is caught by nobody, even if it is SIGINT.
async fn terminate() {
    #[cfg(unix)]
    {
        use tokio::signal::unix::{signal, SignalKind};
        let mut term = signal(SignalKind::terminate()).expect("SIGTERM handler");
        let mut int = signal(SignalKind::interrupt()).expect("SIGINT handler");
        tokio::select! {
            _ = term.recv() => {}
            _ = int.recv() => {}
        }
    }
    #[cfg(not(unix))]
    {
        let _ = tokio::signal::ctrl_c().await;
    }
}
```

```rust
  zyrisd status      Show enrollment, service and capability status
  zyrisd uninstall   Remove the service (--purge drops credentials too)
";

pub async fn dispatch() -> ExitCode {
    let args: Vec<String> = std::env::args().skip(1).collect();
    match args.first().map(String::as_str) {
        Some("run") => run().await,
        Some("enroll") => crate::enroll::enroll().await,
        Some("--version" | "-V") => {
            println!("zyrisd {}", env!("CARGO_PKG_VERSION"));
            ExitCode::SUCCESS
        }
        Some("--help" | "-h") | None => {
            print!("{USAGE}");
            ExitCode::SUCCESS
        }
        Some(other) => {
            eprintln!("Unknown command: {other}\n");
            print!("{USAGE}");
            ExitCode::from(2)
        }
    }
}

async fn run() -> ExitCode {
    let cfg = match config::load() {
        Ok(cfg) => cfg,
        Err(e) => {
            // A restart cannot fix a malformed config.
            tracing::error!(error = %e, "Cannot read the config");
            return ExitCode::from(2);
        }
    };
    ExitCode::from(zyrisd_node::run::run(cfg).await.code())
}
```

```rust
//!
//! `Enroller::obtain()`, when the stored credentials are still valid, **returns them as they
//! are and does not enroll.** So asking "overwrite?" alone never re-enrolls. The store must be
//! cleared first.

use std::io::Write;
use std::process::ExitCode;
use std::sync::Arc;

use zyris::enroll::{CredentialStore, Enroller};

pub async fn enroll() -> ExitCode {
    if unsafe { libc::geteuid() } == 0 {
        eprintln!("Do not run zyrisd enroll as root.");
        eprintln!("Credentials land in /root and the user-session daemon will not find them.");
        return ExitCode::from(2);
    }

    let cfg = match config::load() {
        Ok(cfg) => cfg,
        Err(e) => {
            eprintln!("Cannot read the config: {e}");
            return ExitCode::from(2);
        }
    };

    if let Err(e) = std::fs::create_dir_all(config::config_dir()) {
        eprintln!("Cannot create {}: {e}", config::config_dir().display());
        return ExitCode::from(2);
    }

    let store = zyrisd_node::credentials::file_store();
    match store.load().await {
        Ok(Some(existing)) => {
            println!("This computer is already enrolled.");
            println!("  Account  {}", existing.owner_email);
            println!("  Node     {}", existing.node_name);
            print!("Enroll again? The existing credentials are erased [y/N] ");
            let _ = std::io::stdout().flush();
            let mut answer = String::new();
            if std::io::stdin().read_line(&mut answer).is_err()
                || !matches!(answer.trim(), "y" | "Y")
            {
                println!("Cancelled.");
                return ExitCode::SUCCESS;
            }
            // Stop it first so a running daemon does not rotate with the old token.
            let _ = crate::service::stop_if_active();
            if let Err(e) = store.clear().await {
                eprintln!("Cannot erase the existing credentials: {e}");
                return ExitCode::from(2);
            }
        }
        Ok(None) => {}
        Err(e) => {
            eprintln!("Cannot read the existing credentials: {e}");
            eprintln!("Delete {} and try again.", config::credentials_path().display());
            return ExitCode::from(2);
        }
    }

    let enroller = match Enroller::new(
        &cfg.node.server_url,
        cfg.node.name.clone(),
        platform().to_string(),
        Vec::new(),
        Arc::clone(&store),
    ) {
        Ok(e) => e,
        Err(e) => {
            eprintln!("Cannot prepare enrollment: {e}");
            return ExitCode::from(2);
        }
    };

    match enroller.obtain().await {
        Ok(c) => {
            println!();

            // stuck in failed by RestartPreventExitStatus=2, and nobody else turns it back on.
            crate::service::restart_if_installed();
            ExitCode::SUCCESS

        Err(e) => {
            eprintln!("Enrollment failed: {e}");
            ExitCode::from(2)
        }
    }
}
```

```rust
//! The systemd **user** unit.
//!
//! A system unit cannot work — the PTY shell inherits the daemon environment, and the system
//! manager has no `$SHELL`; `/run/user/<uid>` is 0700 so another uid cannot reach the session;
//! and credentials are 0600, so enroll and the daemon must run under the same uid.
//!
//! Why the unit file is written here and not by the package: `.deb` (`/usr/bin`) and
//! `install.sh` (`~/.local/bin`) want different `ExecStart` lines, and whoever writes it always
//! knows where it is.

use std::path::{Path, PathBuf};
use std::process::Command;

use zyrisd_node::config;

pub fn unit_dir() -> PathBuf {
    config::home()
        .unwrap_or_else(|_| PathBuf::from("/nonexistent"))
        .join(".config/systemd/user")
}

pub fn unit_path() -> PathBuf {
    unit_dir().join("zyrisd.service")
}

pub fn unit_text(exec: &Path, display_bin: Option<&Path>) -> String {
    let exec = exec.display();
    let display_line = match display_bin {
        Some(p) => format!("Environment=ZYRISD_DISPLAY_BIN={}\n", p.display()),
        None => String::new(),
    };
    format!(
        "[Unit]\n\
         Description=Zyris daemon\n\
         # Remove the package first and ExecStart is gone. That failure is 203/EXEC, not exit\n\
         # code 2, so without this guard the unit spins in a restart loop.\n\
         ConditionPathExists={exec}\n\
         \n\
         [Service]\n\
         Type=simple\n\
         ExecStart={exec} run\n\
         {display_line}\
         RuntimeDirectory=zyrisd\n\
         Restart=on-failure\n\
         RestartSec=5\n\
         # Exit code 2 means a human has to step in. A restart cannot fix it.\n\
         RestartPreventExitStatus=2\n\
         # Trim the default 90 seconds. This budget is not the daemon's (200ms); on expiry the\n\
         # whole cgroup is SIGKILLed, so it is grace for the PTY children the agent opened.\n\
         TimeoutStopSec=10\n\
         \n\
         [Install]\n\
         WantedBy=default.target\n"
    )
}

fn systemctl(args: &[&str]) -> std::io::Result<std::process::ExitStatus> {
    Command::new("systemctl").arg("--user").args(args).status()
}

fn unit_is_installed() -> bool {
    unit_path().exists()
}

pub fn stop_if_active() -> std::io::Result<()> {
    if unit_is_installed() {
        systemctl(&["stop", "zyrisd.service"])?;
    }
    Ok(())
}

/// Called once enrollment finishes.
///
/// A unit stopped by a cancel exiting 2 is stuck in failed by `RestartPreventExitStatus=2`,
/// and without `reset-failed` even `restart` does nothing. Without this there is no way back
/// along the very path the product used to call the human.
pub fn restart_if_installed() {
    if !unit_is_installed() {
        println!();
        println!("Run `zyrisd install` now and it connects on every boot.");
        return;
    }
    let _ = systemctl(&["reset-failed", "zyrisd.service"]);
    match systemctl(&["restart", "zyrisd.service"]) {
        Ok(s) if s.success() => println!("Service restarted."),
        _ => println!("Could not restart the service: systemctl --user restart zyrisd"),
    }
}

fn display_helper_beside(exec: &Path) -> Option<PathBuf> {
    let parent = exec.parent()?;
    let candidates = [
        parent.join("../libexec/zyrisd-display"),
        parent.join("zyrisd-display"),
        PathBuf::from("/usr/libexec/zyrisd-display"),
    ];
    candidates.into_iter().find(|p| p.exists()).and_then(|p| p.canonicalize().ok())
}

pub fn install() -> anyhow::Result<()> {
    if unsafe { libc::geteuid() } == 0 {
        anyhow::bail!("Do not run zyrisd install as root. It is a user session service.");
    }
    if std::env::var_os("XDG_RUNTIME_DIR").is_none() {
        anyhow::bail!("XDG_RUNTIME_DIR is unset. Run this from a graphical or login session.");
    }

    let exec = std::env::current_exe()?;
    let display_bin = display_helper_beside(&exec);
    let text = unit_text(&exec, display_bin.as_deref());

    std::fs::create_dir_all(unit_dir())?;
    let changed = std::fs::read_to_string(unit_path()).ok().as_deref() != Some(text.as_str());
    if changed {
        std::fs::write(unit_path(), &text)?;
        systemctl(&["daemon-reload"])?;
    }

    // Without linger the user manager only comes up at login, so "starts at boot" is a lie.
    let user = std::env::var("USER").unwrap_or_default();
    let _ = Command::new("loginctl").args(["enable-linger", &user]).status();

    systemctl(&["enable", "zyrisd.service"])?;
    // `start` is a no-op on an active unit; if it changed, only restart runs the new binary.
    let _ = systemctl(&["reset-failed", "zyrisd.service"]);
    systemctl(&[if changed { "restart" } else { "start" }, "zyrisd.service"])?;

    report_liveness();
    Ok(())
}

/// With `Type=simple`, `start` returns success right after the fork. Only checking that it is
/// really alive keeps "install complete" from being a lie.
fn report_liveness() {
    for _ in 0..10 {
        std::thread::sleep(std::time::Duration::from_millis(300));
        let active = Command::new("systemctl")
            .args(["--user", "is-active", "zyrisd.service"])
            .output()
            .ok()
            .map(|o| String::from_utf8_lossy(&o.stdout).trim().to_string());
        match active.as_deref() {
            Some("active") => {
                println!("zyrisd is running. It connects on every boot.");
                return;
            }
            Some("failed") => break,
            _ => continue,
        }
    }
    eprintln!("zyrisd did not come up. Check that enrollment finished:");
    eprintln!("  zyrisd status");
    eprintln!("  journalctl --user -u zyrisd -n 30");
}

pub fn uninstall(purge: bool) -> anyhow::Result<()> {
    let _ = systemctl(&["stop", "zyrisd.service"]);
    let _ = systemctl(&["disable", "zyrisd.service"]);
    if unit_path().exists() {
        std::fs::remove_file(unit_path())?;
    }
    let _ = systemctl(&["daemon-reload"]);

    let user = std::env::var("USER").unwrap_or_default();
    let _ = Command::new("loginctl").args(["disable-linger", &user]).status();

    if let Some(dir) = std::env::var_os("XDG_RUNTIME_DIR") {
        let _ = std::fs::remove_dir_all(PathBuf::from(dir).join("zyrisd"));
    }

    if purge {
        let _ = std::fs::remove_dir_all(config::config_dir());
        println!("Credentials and config erased.");
    } else {
        println!("Credentials kept. Use --purge to erase them.");
    }
    println!("Uninstalled.");
    Ok(())
}
```

```rust
//! Runtime state the daemon leaves behind and `zyrisd status` reads.
//!
//! The announce set lives only in daemon memory and shifts as the display helper comes and goes.
//! `status`, a separate process, cannot learn it from the config alone.

use std::path::PathBuf;

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct State {
    pub node_name: String,
    pub connected: bool,
    pub capabilities: Vec<String>,
    pub updated_unix: i64,
}

pub fn path() -> Option<PathBuf> {
    let dir = std::env::var_os("XDG_RUNTIME_DIR")?;
    Some(PathBuf::from(dir).join("zyrisd").join("state.json"))
}

/// Ignores failures. A state file it cannot write is no reason to stop the daemon.
pub fn write(state: &State) {
    let Some(path) = path() else { return };
    let Some(dir) = path.parent() else { return };
    if std::fs::create_dir_all(dir).is_err() {
        return;
    }
    let tmp = path.with_extension("json.tmp");
    let Ok(text) = serde_json::to_string_pretty(state) else { return };
    if std::fs::write(&tmp, text).is_ok() {
        let _ = std::fs::rename(&tmp, &path);
    }
}

pub fn read() -> Option<State> {
    let text = std::fs::read_to_string(path()?).ok()?;
    serde_json::from_str(&text).ok()
}
```

```rust
//! Puts something on screen when a human has to be called.
//!
//! The point is to **re-read the session environment every time**. A linger-started daemon's
//! boot environment has no `DISPLAY` and no `DBUS_SESSION_BUS_ADDRESS`, and a later login's
//! `import-environment` does not reach back into a process that is already running.

use std::process::Command;

const WANTED: [&str; 4] =
    ["DISPLAY", "WAYLAND_DISPLAY", "XAUTHORITY", "DBUS_SESSION_BUS_ADDRESS"];

fn parse_environment(raw: &str) -> Vec<(String, String)> {
    raw.lines()
        .filter_map(|line| line.split_once('='))
        .filter(|(k, _)| WANTED.contains(k))
        .map(|(k, v)| (k.to_string(), v.to_string()))
        .collect()
}

pub fn session_env() -> Vec<(String, String)> {
    Command::new("systemctl")
        .args(["--user", "show-environment"])
        .output()
        .ok()
        .filter(|o| o.status.success())
        .map(|o| parse_environment(&String::from_utf8_lossy(&o.stdout)))
        .unwrap_or_default()
}

/// Best effort. Missing binary or no session and it passes quietly — the log always says why.
///
/// The body is a fixed string zyrisd owns. Whatever the server sent goes to the log only.
/// `--` ends option parsing so a summary starting with `-` is not eaten as an option.
pub fn needs_attention(summary: &str, body: &str) {
    let mut cmd = Command::new("notify-send");
    cmd.arg("--app-name=zyrisd").arg("--urgency=critical").arg("--").arg(summary).arg(body);
    for (k, v) in session_env() {
        cmd.env(k, v);
    }
    match cmd.status() {
        Ok(s) if s.success() => {}
        _ => tracing::debug!("Could not raise the desktop notification"),
    }
}
```

```rust
//! Framing between the zyrisd parent and the desktop child.
//!
//! One frame = `[u32 BE json_len][json][u32 BE blob_len][blob]`.
//! Screenshot bytes ride in the blob frame, so there is no base64 bloat.
//!
//! **The child's stdout carries frames only; logs go to stderr.** Mixing them breaks framing.

use std::io::{self, Read, Write};

use serde::{Deserialize, Serialize};

pub const JSON_MAX: usize = 1 << 20;
pub const BLOB_MAX: usize = 8 << 20;

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "op")]
pub enum Request {
    Probe,
    ListDisplays,
    Screenshot {
        display: Option<u32>,
        region: Option<Region>,
        format: Option<String>,
        max_width: Option<u32>,
    },
    MoveTo { x: i32, y: i32 },
    Click { button: String },
    Key { key: String },
    Type { text: String },
    Scroll { dx: i32, dy: i32 },
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub struct Region {
    pub x: i32,
    pub y: i32,
    pub width: u32,
    pub height: u32,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct DisplayInfo {
    pub id: u32,
    pub name: String,
    pub width: u32,
    pub height: u32,
}

/// Why the screenshot response carries meta too: the capability's return is not a raw blob but
/// `Datum::Image{name, description, media_type, blob}`, and `description` can only be computed
/// by the child — after downscaling to fit the budget, image coordinates drift from display
/// coordinates, and `description` is where that scale factor is recorded.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct ImageMeta {
    pub resolved_display_id: u32,
    pub sent_width: u32,
    pub sent_height: u32,
    pub media_type: String,
    pub description: String,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "kind")]
pub enum Response {
    Probe { displays: Vec<DisplayInfo>, input_ok: bool },
    Displays { displays: Vec<DisplayInfo> },
    Image { meta: ImageMeta },
    Ok,
    Error { message: String },
}

pub struct Frame {
    pub id: u64,
    pub body: serde_json::Value,
    pub blob: Vec<u8>,
}

pub fn write_frame<W: Write>(
    w: &mut W,
    id: u64,
    body: &impl Serialize,
    blob: &[u8],
) -> io::Result<()> {
    let envelope = serde_json::json!({ "id": id, "body": serde_json::to_value(body)? });
    let json = serde_json::to_vec(&envelope)?;
    if json.len() > JSON_MAX || blob.len() > BLOB_MAX {
        return Err(io::Error::new(io::ErrorKind::InvalidData, "frame exceeds the limit"));
    }
    w.write_all(&(json.len() as u32).to_be_bytes())?;
    w.write_all(&json)?;
    w.write_all(&(blob.len() as u32).to_be_bytes())?;
    w.write_all(blob)?;
    w.flush()
}

fn read_len<R: Read>(r: &mut R, max: usize) -> io::Result<usize> {
    let mut buf = [0u8; 4];
    r.read_exact(&mut buf)?;
    let len = u32::from_be_bytes(buf) as usize;
    if len > max {
        return Err(io::Error::new(io::ErrorKind::InvalidData, "frame length exceeds the limit"));
    }
    Ok(len)
}

pub fn read_frame<R: Read>(r: &mut R) -> io::Result<Frame> {
    let json_len = read_len(r, JSON_MAX)?;
    let mut json = vec![0u8; json_len];
    r.read_exact(&mut json)?;
    let envelope: serde_json::Value = serde_json::from_slice(&json)?;
    let id = envelope.get("id").and_then(serde_json::Value::as_u64).unwrap_or(0);
    let body = envelope.get("body").cloned().unwrap_or(serde_json::Value::Null);

    let blob_len = read_len(r, BLOB_MAX)?;
    let mut blob = vec![0u8; blob_len];
    r.read_exact(&mut blob)?;
    Ok(Frame { id, body, blob })
}
```

```rust
//! zyrisd's desktop helper. The only binary that links graphics libraries.
//!
//! Reads frames from stdin, answers on stdout. **stdout is frames only; logs go to stderr.**
//! It exits when stdin closes, so a dead parent leaves no orphan.

mod probe;

use std::io::{Read, Write};

use zyrisd_display_proto::{read_frame, write_frame, Request, Response};

fn main() {
    tracing_subscriber::fmt()
        .with_writer(std::io::stderr)
        .with_env_filter(
            tracing_subscriber::EnvFilter::try_from_default_env()
                .unwrap_or_else(|_| "zyrisd_display=info".into()),
        )
        .init();

    let stdin = std::io::stdin();
    let stdout = std::io::stdout();
    let mut reader = stdin.lock();
    let mut writer = stdout.lock();

    loop {
        let frame = match read_frame(&mut reader) {
            Ok(f) => f,
            // The parent is gone. Leave quietly.
            Err(_) => return,
        };
        let response = match serde_json::from_value::<Request>(frame.body) {
            Ok(req) => handle(req),
            Err(e) => (Response::Error { message: e.to_string() }, Vec::new()),
        };
        if write_frame(&mut writer, frame.id, &response.0, &response.1).is_err() {
            return;
        }
    }
}

fn handle(req: Request) -> (Response, Vec<u8>) {
    match req {
        Request::Probe => {
            let displays = probe::displays();
            // Announce input only when the display server actually accepts it. Advertising
            // it and failing every time is worse than not showing up at all — the agent
            // has no way to tell the two apart.
            let input_ok = !displays.is_empty() && input_works();
            (Response::Probe { displays, input_ok }, Vec::new())
        }
        Request::ListDisplays => (Response::Displays { displays: probe::displays() }, Vec::new()),
        Request::Screenshot { .. } => todo!("Step 3"),
        _ => todo!("Step 3"),
    }
}

fn input_works() -> bool {
    std::panic::catch_unwind(|| {
        zyris_capkit::EnigoInput::new(zyris_capkit::HostDisplays(
            zyris_capkit::HostScreenCapture::default().backend(),
        ))
        .is_ok()
    })
    .unwrap_or(false)
}
```

```rust
//! Watches the desktop child live or die and attaches or detaches the capability.

use std::path::PathBuf;
use std::time::Duration;

use crate::config::DesktopConfig;

/// Search order. `PATH` is left out on purpose — see the comment on the test above.
pub fn helper_path() -> Option<PathBuf> {
    if let Some(p) = std::env::var_os("ZYRISD_DISPLAY_BIN").map(PathBuf::from) {
        if p.exists() {
            return Some(p);
        }
    }
    let exe = std::env::current_exe().ok()?;
    let dir = exe.parent()?;
    let candidates = [
        dir.join("../libexec/zyrisd-display"),
        dir.join("zyrisd-display"),      // convenience for cargo run
        PathBuf::from("/usr/libexec/zyrisd-display"),
    ];
    candidates.into_iter().find(|p| p.exists()).and_then(|p| p.canonicalize().ok())
}

/// If the child dies, drop the capability and retry with backoff. A later screen still attaches.
pub async fn watch(caps: zyris::Capabilities, cfg: DesktopConfig, on_change: impl Fn() + Send) {
    if !cfg.enabled {
        return;
    }
    let mut backoff = Duration::from_secs(1);
    loop {
        match try_attach(&caps).await {
            Ok(child) => {
                backoff = Duration::from_secs(1);
                on_change();
                child.wait().await;                       // until the child dies
                caps.remove("screen_capture").await;
                caps.remove("input").await;
                on_change();
            }
            Err(e) => tracing::debug!(error = %e, "could not attach the desktop helper"),
        }
        tokio::time::sleep(backoff).await;
        backoff = (backoff * 2).min(Duration::from_secs(60));
    }
}
```

`try_attach` (1) spawns the child from `helper_path()` **injecting `notify::session_env()`**,
(2) sends `Probe`, (3) on one or more displays calls `caps.add(ScreenCaptureServer(proxy))`, and
if `input_ok`, `caps.add(InputServer(proxy))`.

**Only `add`/`remove`; never pass `replace()` a new instance.** Those two rebuild from the old `Arc`,
so `PtyTerminal` is never dropped.

The proxy implements the `zyris_caps::{ScreenCapture, Input}` traits; each method sends its request
down the channel and waits. On timeout it kills the child (kill + reap) and restarts. On EOF or a
partial frame it **fails the in-flight request immediately** — else the caller hangs to timeout.

`run.rs` spawns `display::watch` as a third branch and kill+reaps the child on the shutdown path.

## Task E2: `install.sh`

**Files:**
- Create: `install.sh`

- [ ] **Step 1: write the script**

```sh
#!/bin/sh
# zyrisd install script.
#
# **It only places the binaries.** Enrollment and starting the service are done by a human.
# Running `zyrisd install` here would start the daemon unenrolled, it dies with exit 2, and
# RestartPreventExitStatus=2 freezes the unit as failed. Because it is Type=simple,
# `enable --now` returns success right after the fork, so this script never learns any of it
# and prints "install complete" anyway.
set -eu

BASE_URL="${ZYRISD_BASE_URL:-https://github.com/attacca-cc/zyris-daemon/releases/latest/download}"
PREFIX="${ZYRISD_PREFIX:-$HOME/.local}"

die() { echo "error: $*" >&2; exit 1; }

[ "$(uname -s)" = "Linux" ] || die "only Linux is supported for now (uname: $(uname -s))"
case "$(uname -m)" in
  x86_64)  ARCH=x86_64 ;;
  aarch64) ARCH=aarch64 ;;
  *) die "unsupported architecture: $(uname -m)" ;;
esac

command -v curl >/dev/null 2>&1 || die "curl is required"
command -v tar  >/dev/null 2>&1 || die "tar is required"

# Don't judge by the exit code of is-system-running. One unrelated degraded unit would
# make it call a healthy machine broken.
[ -n "${XDG_RUNTIME_DIR:-}" ] || die "XDG_RUNTIME_DIR is unset. Run this from a login session"
systemctl --user show -p Version >/dev/null 2>&1 ||
  die "systemctl --user is not available"

TARBALL="zyrisd-${ARCH}-linux.tar.gz"
TMP="$(mktemp -d)"
trap 'rm -rf "$TMP"' EXIT

echo "downloading: ${BASE_URL}/${TARBALL}"
curl -fsSL "${BASE_URL}/${TARBALL}" -o "${TMP}/${TARBALL}" || die "download failed"
curl -fsSL "${BASE_URL}/SHA256SUMS" -o "${TMP}/SHA256SUMS" || die "could not fetch checksums"

# Checksums come from the same host — **this catches transfer corruption only.** Not supply-chain proof.
( cd "$TMP" && grep " ${TARBALL}\$" SHA256SUMS | sha256sum -c - ) ||
  die "checksum mismatch"

mkdir -p "${PREFIX}/bin" "${PREFIX}/libexec"
tar xzf "${TMP}/${TARBALL}" -C "$TMP"
install -m 755 "${TMP}/zyrisd" "${PREFIX}/bin/zyrisd"
[ -f "${TMP}/zyrisd-display" ] &&
  install -m 755 "${TMP}/zyrisd-display" "${PREFIX}/libexec/zyrisd-display"

cat <<MSG

zyrisd is installed at ${PREFIX}/bin/zyrisd.

Two steps remain — run them from the path just installed:

  ${PREFIX}/bin/zyrisd enroll     registers this computer with your Attacca account
  ${PREFIX}/bin/zyrisd install    connects automatically on every boot

MSG
```

`chmod +x install.sh`.

Why the notice uses absolute paths: resolving by name on a machine that already has the `.deb`
could pick up the old `/usr/bin/zyrisd`.

```bash
tar czf zyrisd-x86_64-linux.tar.gz zyrisd zyrisd-display 2>/dev/null || tar czf zyrisd-x86_64-linux.tar.gz zyrisd
sha256sum zyrisd-x86_64-linux.tar.gz > SHA256SUMS
cd /home/ruma/zyris-daemon
ZYRISD_BASE_URL="file:///tmp/zyrisd-rel" ZYRISD_PREFIX=/tmp/zyrisd-test sh install.sh
```
